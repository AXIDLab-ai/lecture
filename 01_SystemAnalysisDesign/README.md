# 시스템분석설계

**System Analysis and Design · 2025-2 아카이브**

비즈니스 요구사항을 체계적으로 분석하고, SDLC와 모델링 기법을 활용해 실행 가능한 정보시스템 설계로 전환하는 과목입니다.

[강의 로드맵 보기 →](./lectureMap.md)

## 강의 개요

| 항목 | 내용 |
|---|---|
| 대상 | 한국공학대학교 경영학부 3학년 · 전공필수 |
| 학습 방식 | 강의, 모델링 실습, 팀 프로젝트 |
| 핵심 주제 | SDLC, 요구사항, DFD, Use Case, ERD, 데이터베이스, 구현·운영 |
| 주요 도구 | Draw.io, PlantUML, Figma, GitHub |

## 학습 목표

1. 조직의 문제와 이해관계자 요구를 기능·비기능 요구사항으로 구조화합니다.
2. 프로세스와 데이터를 DFD, Use Case, ERD 등으로 모델링합니다.
3. 분석 결과를 설계, 구현, 테스트, 배포와 운영 계획으로 연결합니다.
4. 팀 기반 프로젝트에서 산출물의 추적성과 변경 이력을 관리합니다.

## 주차별 자료

[전체 강의 로드맵](./lectureMap.md)에서 공개된 주차별 강의노트와 학습 순서를 확인할 수 있습니다.

- 1–6주: SDLC, 방법론, 구조적 분석, 프로젝트 관리, 시스템 계획, 요구사항 조사
- 8–11주: 프로세스·데이터 모델링, 저장소 설계, 데이터베이스 최신 동향
- 13주: 구현, 테스트, 배포, DevOps와 운영

> 7·12·14·15주는 시험 또는 프로젝트 발표 중심으로 운영되어 별도 공개 노트가 없습니다.
