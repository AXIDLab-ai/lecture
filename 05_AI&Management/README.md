**AI & Management · 2026-2**

## 학습 목표

1. 예측형 AI와 생성형 AI의 차이, 적용 조건, 한계를 설명합니다.
2. 데이터 품질과 모델 평가 지표를 경영 의사결정의 위험과 연결합니다.
3. AI 에이전트와 자동화 흐름에서 사람의 승인·통제 지점을 설계합니다.
4. 알고리즘의 가치 충돌을 시나리오와 측정 변수로 조작화합니다.
5. 시뮬레이션 로그를 근거로 편향과 실패 모드를 감사합니다.
6. 성능뿐 아니라 책임성, 투명성, 안전성을 포함한 배포 판단을 제안합니다.
