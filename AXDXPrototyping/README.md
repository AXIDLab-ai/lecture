## 학습 목표

1. 고객과 현장 맥락을 바탕으로 검증 가능한 서비스 문제를 정의합니다.
2. PRD, 인수조건, 데이터 모델과 KPI로 요구사항을 구체화합니다.
3. AI 생성 코드를 테스트와 보안·품질 체크리스트로 비판적으로 검토합니다.
4. 동작하는 프로토타입을 배포하고 사용자 행동 데이터로 가설을 평가합니다.

## 공개 자료 구성

- **1–4주 기획 노트**: AX/DX 기초, 프로젝트 캔버스, 서비스 분석, BMC와 시장 검증
- **11–14주 기존 설계 노트**: 개념설계, 상세설계, UI/UX, 프로토타이핑
- **11–14주 바이브코딩 워크숍**: 요구사항, UI 테스트, 데이터·KPI, 배포·실험

두 종류의 11–14주 자료는 목적이 다릅니다. 기존 설계 노트는 서비스 설계 개념을, 워크숍 노트는 2026년 실습 흐름을 다룹니다.
