# 경영정보시스템

**Management Information Systems · 2026-1 아카이브**

정보시스템을 단순한 기술 도입이 아니라 조직 성과를 만드는 사회기술 시스템으로 분석합니다. 전략, 사람·구조, 데이터, 프로세스, 거버넌스, 경쟁우위의 6-Lens 프레임을 사용합니다.

## 학습 목표

수강 후 다음을 수행할 수 있어야 합니다.

1. 비즈니스 전략과 IT 역량의 정렬 여부를 진단합니다.
2. 사회기술시스템 관점에서 도입 성공·실패 조건과 변화관리 방안을 설명합니다.
3. 데이터에서 의사결정까지의 흐름과 정보 품질·KPI를 설계합니다.
4. E2E 프로세스, 전사 통합, EA와 데이터 거버넌스를 연결합니다.
5. 플랫폼, 데이터 자산, 네트워크 효과 관점에서 경쟁우위를 평가합니다.
6. AX 도입의 가치, 리스크, 책임 구조를 근거 기반으로 제안합니다.

## 수업 방식

강의와 케이스 토의, 팀 기반 사례개발 프로젝트로 운영합니다. 프로젝트는 기업의 성공담을 요약하는 대신, 시스템이 작동하거나 실패하는 경계조건과 개입 방안을 구조화합니다.
